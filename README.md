# 42-cub3D
cub3D is a project inspired by the classic Wolfenstein 3D game, where we create a simple 3D first-person view inside a maze using ray-casting and the MiniLibX graphics library.

→ Things to learn

- MiniLibX documentation and graphics rendering
- Parsing and validating .cub configuration files
- Map handling (dimensions, spaces, and closed wall validation)
- Ray-casting algorithm and DDA logic
- Player movement, rotation, mouse control and collision detection
- Wall distance calculation and fish-eye correction
- Texture loading and texture mapping
- RGB color handling for floor and ceiling
- Memory management and debugging in C
